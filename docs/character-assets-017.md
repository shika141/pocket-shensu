# 沈溯角色素材與自主動作規格 017

## 既有素材盤點

遊戲使用 `public/assets/character/` 的透明單人 PNG，不使用整張設定集作為遊戲立繪。現有 013 立繪的 Alpha 可見範圍都貼合圖片畫布，沒有大量透明留白；尺寸約 80–99 × 140–147 px。CSS 只設定顯示高度與 `width: auto`，以完整長寬比縮放，圖片腳底對齊角色錨點。

| 服裝／姿勢 | 現有檔案 | MVP 顯示方式 |
|---|---|---|
| 日常服站立 | `shensu-casual-013.png` | 原比例站立 |
| 居家服站立／抱娃娃 | `shensu-home-013.png`／`shensu-home-010.png` | 依姿勢選圖 |

| 睡姿 | `shensu-sleep-010.png` | 睡眠時放到臥室床面 |

## 命名規則

- 動作序列：`shensu-{outfit}-017-{pose}-{frame}.webp`
- 單張姿勢：`shensu-{outfit}-017-{pose}.png`
- `{outfit}`：`casual`、`home`、`training`、`swim`、`sleep`、`shark`
- `{pose}`：`stand`、`walk`、`sit`、`hug`、`sleep`
- 序列首格與末格需能無縫循環；每張圖以腳底／床面接觸點對齊同一畫布基線，保留透明背景及一致角色大小。
- 動作圖要與服裝分開提供；沒有該服裝的姿勢圖時沿用同服裝站姿，不借用其他服裝姿勢。

## 場景定位

`src/08_autonomy.ts` 為四場景各自設定桌面、手機的安全行走帶、起始位置、家具禁入區和家具互動座標。角色座標以腳底中心為基準。行走只在同一安全帶內挑選目的地；睡眠姿勢移到臥室床面，客廳鯊魚裝坐姿移到沙發。桌面與手機使用不同的場景座標。

## 自主行動資料範圍

行動狀態（站立、走路、坐下、抱娃娃、睡覺）只存在 React 畫面狀態中。它不寫進 `GameState`，不增加 revision，也不觸發本機或 Supabase 存檔。玩家操作時會結束目前短動作；換場景會採新場景的起點。
